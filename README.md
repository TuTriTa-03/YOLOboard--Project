# Embedded Systems & IoT Projects

A collection of embedded systems and Internet of Things (IoT) projects developed as part of my learning journey in embedded software engineering.

The projects focus on embedded C++, microcontroller programming, real-time operating systems, hardware interfaces, and network communication.

## Hardware Platform

- **Development Board:** Yolo UNO S3
- **Microcontroller:** ESP32-S3
- **Development Environment:** Visual Studio Code + PlatformIO

## Projects

### 1. LED Blinky

A foundational embedded C++ project for learning LED control, ESP32-S3 programming, and FreeRTOS concepts.

**Technologies:** C++, ESP32-S3, PlatformIO, FreeRTOS

See [LED Blinky Documentation](README_LED_BLINKY.md).

### 2. DHT20 Environmental Monitoring

*Planned / in development.*

An environmental monitoring project using the DHT20 temperature and humidity sensor. The project focuses on I2C communication, sensor data acquisition, and embedded data processing.

**Planned technologies:** C++, ESP32-S3, DHT20, I2C.

## Learning Objectives

- Develop practical embedded C++ programming skills.
- Understand microcontroller peripherals and hardware interfaces.
- Learn FreeRTOS task management and inter-task communication.
- Explore Wi-Fi connectivity and IoT system design.
- Apply modular code organization and version control using Git.
